# FitTrack v2

A privacy-first installable mobile web app for daily calories, water, weight, exercise, progress photos, charts and weekly coaching.

## Install on phone
1. Put this folder on an HTTPS static host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the HTTPS site on your phone.
3. Use the browser's **Add to Home Screen / Install App** option.
4. The app works offline after the first load.

## Important
The app intentionally does NOT claim to diagnose body fat, health conditions, or make precise body measurements from photos. It stores progress photos locally and gives practical guidance about making photo comparisons consistent.

For true AI photo analysis, add a secure backend that sends photos to a vision model. Never put an API key directly into this mobile frontend.

## Included
- Daily calories, water, weight, exercise and notes
- Daily progress photo
- 7-day weight graph
- Weekly report and coaching tips
- Photo timeline
- Streak
- Goal settings
- Local data storage
- Offline PWA
- Exportable weekly report
